# Adventure Works Sales Dashboard

### 📊 Project Overview
Analyzed Microsoft's Adventure Works global sales dataset to deliver sales, product, and territory performance insights for business decision-making.

### 🛠️ Tools Used
- **SQL:** Joins, CTEs, Window Functions for data cleaning & KPI calculation
- **Excel:** Pivot Tables, Data Cleaning
- **Power BI:** Interactive Dashboard with 5+ Visuals, Slicers, DAX Measures

### 📈 KPIs & Insights
- Total Sales: $XX M | Total Profit: $XX M | Total Orders: XXK
- YoY Sales Growth Analysis
- Top 5 Products by Sales
- Sales by Territory / Region
- Customer Segmentation & Buying Trends

### 📁 Files in this Repo
- `AdventureWorks_Data.xlsx` - Raw Dataset
- `SQL_Queries.sql` - SQL Analysis
- `PowerBI_Dashboard.pbix` - Interactive Dashboard
- `Dashboard_Screenshots/` - Dashboard Images

### 💡 Business Impact
Helped identify high-performing products and regions, enabling data-driven sales strategy.
